# Portfolio Website

A modern, minimalistic portfolio website built with React and Vite.

## Setup Instructions

1. Install dependencies:
```bash
npm install
```

2. Set up Formspree:
   - Go to [Formspree.io](https://formspree.io) and create a free account
   - Create a new form and copy your form ID
   - Open `src/components/Contact.jsx`
   - Replace `YOUR_FORM_ID` with your actual Formspree form ID

3. Run the development server:
```bash
npm run dev
```

4. Build for production:
```bash
npm run build
```

## Features

- Modern, minimalistic design
- Fully responsive
- Smooth scrolling navigation
- Formspree contact form integration
- All projects and experience from resume showcased
